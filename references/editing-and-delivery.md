# 编辑、渲染与交付

## 编辑边界

保留源文件副本，识别最新批准版。新增内容延续已认可的字体、配色、插画、标题位置和图形语言。避免从旧脚本重建而恢复旧内容或旧样式。

纯表格美化保留文字、数值、数量、位置、所有 Notes、页序、其他原生对象与图片。发现内容错误时记录为独立问题，不在美化中悄悄改含义。

## 样式移植脚本

全量导出影响其他内容时，可以从原生工具导出文件移植表格。脚本仅使用 Python 标准库：

```bash
python3 scripts/preserve_table_styles.py \
  --source original.pptx \
  --styled native-edited.pptx \
  --slides 5,10,17 \
  --output refined.pptx \
  --report validation.json
```

`--slides` 为显示顺序中的一基页码。脚本通过 presentation relationships 解析实际 part，不能将文件名编号当作页序。

脚本验证页数、逐表逐单元格文字、合并属性、行列尺寸与表格顺序，拒绝图片或关系依赖，确认 donor 引用的样式定义在原包存在且一致。只替换 `<a:tbl>`，保留原始表格框、布局、连接线、Notes、媒体及其他包成员。输出不覆盖已有文件；重新验证其他字节未变并写报告。

拒绝时先定位原因，不放宽检查强行移植。请求内容或结构变化时，正常用原生编辑工具并全面检查。带图片、链接或外部样式依赖的表格需要关系感知的编辑方式。

## 渲染

实际查看最终候选文件的渲染。缩略图总览检查节奏、一致性与重复版式；每张新建或修改页还需放大看文字、表格和细节。

- 中文无缺字，英文和数字正常；标题、注释、标签无裁切、重叠或意外换行。
- 插画比例和裁切合理，未以整页截图交付。
- 表格在投影尺度可读，主题没有叠加意外边框。
- 流程起止、分支、箭头和回环清楚，静态能力未误画成执行顺序。
- 成功、失败、等待和人工介入有出口；演示区分现场运行、历史记录与推演。

仅当证明其他包成员和页面对象字节不变时，才复用其已检查渲染；重新渲染所有修改页，再看全套总览。无此证据则重新渲染全套。

## 验收与交付

核对页数与 Notes，知识页备注有实际内容。确认文本、技术图、连接线和表格仍为原生对象，插画为独立图片。对最终文件做导入 / 包完整性检查，不能仅凭脚本成功退出断言制作成功。

PDF 可由实际渲染页制作，用于浏览。不要称其为可编辑 PPT，也不要声称做过未执行的 PowerPoint 或 Keynote 客户端检查。

按需提供 PPTX、PDF_Previews、Overviews、Original_Illustrations、Instructor_Notes.txt 和全套 ZIP。更新最终文件后同步预览与压缩包，核对 ZIP 内 PPTX 与交付链接文件一致。donor、备份、日志、代码与内部验证报告不默认打包给学员。
