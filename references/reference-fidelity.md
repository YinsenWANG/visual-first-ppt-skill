# 参考基准与风格防漂移

用于用户给出满意样稿、要求沿用设计，或认为后续课件发生风格漂移的任务。无参考时，也可把本仓库的 FDE 示例作为默认风格起点；新的品牌要求始终优先。

## 先分清内容与视觉的来源

在内部记录两项：`内容来源：最新完整稿`、`视觉基准：用户明确认可的样稿`。旧稿可能是最佳视觉参考，新稿可能是完整内容来源，二者不能因时间先后被混为一谈。不要恢复旧内容来换取旧外观。

读取实际页面，不仅阅读生成脚本或风格文字。已有预览先核对是否对应同一 PPTX：页数、标题、代表页均应匹配。历史预览未覆盖最新增补时，重新渲染相关页面再判断。

选择能体现设计的封面、章节、概念关系图、流程、表格与插画页，记录：

- 画布比例、标题和正文锚点、边距、字级与字重。
- 主色、辅助色、状态色的角色，以及白底和色块的面积关系。
- 构图与视觉重心：主要信息靠什么图形关系表达，插画在画面中占多大。
- 章节、页码、表格分隔线、提示条的实际使用方式。
- 插画人物比例、取景、场景密度、阴影与背景留白。

将这些可检查的特征写入简短视觉档案。复述“高级、简洁、扁平”不能替代档案。

## FDE 参考档案

这是一套已认可课件的具体风格，不是所有演示文稿的硬性标准。参考 [封面](../assets/slide-examples/cover.png)、[流程](../assets/slide-examples/workflow.png)、[表格](../assets/slide-examples/table.png) 和 [章节](../assets/slide-examples/divider.png)。这些文件仅用于对照风格与构图，其中插画不作为新课件的固定素材；新插图按当前内容调用 ImageGen 生成。下列坐标按 1280 × 720 画布描述，其他尺寸同比换算。

| 项目 | FDE 参考特征 |
| --- | --- |
| 页面底色 | 白色为主，留白包围内容；浅色集中在节点、表头与少量提示区域 |
| 标题 | 左缘约 x=64，正文页标题约 y=95，常用 44 px / 33 pt；不是每页的大号宣传口号 |
| 章节小标 | 约 x=64、y=34，亮蓝小字，与主标题留出间隔 |
| 正文与标签 | 按内容大约 23–29 px / 17–22 pt；不是全局强制字号，先参考对应类型页面 |
| 文字颜色 | 主要文字近黑 `#111827`，说明灰 `#667085`，关键标签深蓝 `#1D438D` |
| 色彩 | 主蓝 `#356CF5`，浅蓝 `#E8EEFF`，辅以紫 `#6E49E8`、青绿 `#08C8B5`，少量橙黄 |
| 章节页 | 白底，左侧细色边；左上大号浅色数字，下方短章节名，右侧少量几何呼应；直接复用样稿对象最可靠 |
| 关系图 | 轻量短节点、清晰连接、局部强调关键节点；附注与节点分离，异常路径有位置与颜色区别 |
| 表格 | 浅表头、白正文、细横线，强调第一列或关键数值；不用整表灰蓝交替色带填充 |
| 插画 | 轻巧的二维人物与工作场景，抽象的 Agent 元素按主题使用；有色主体周围留白，避免半身肖像占满半页 |
| 页脚 | 简短课程标识和页码，弱化，不默认添加贯穿每页的长横线和完整课程标题 |

字体从源文件读取并核对可用性，不依据以上截图猜测替代字体。坐标与字号作为复刻此风格的起点，实际长标题、表格和操作页仍需渲染调整。

## 代表页先通过，再扩展

先完成能暴露差异的代表页：封面、章节、核心关系图，以及最密集的表格或截图页。无需每次强制等待用户批准；已有清晰授权与参考时可自行对照修正后继续。

把新页与对应样稿按同一显示尺寸并排查看，依次判断：

1. 第一眼的视觉主体是否一致：是关系图、操作证据还是长段说明？
2. 构图、标题锚点、色彩角色、插画重量是否仍属于同一套课件？
3. 必需内容是否保留，换成图后是否引入错误关系？
4. 在投影尺度能否辨认关键节点、字段和表格？

若仅颜色相近，但构图和信息表达显著不同，不能作为风格匹配通过。批量制作中出现新的页面类型时，重新做一次代表页对照。修复漂移时优先回到已验证样稿，不从待修稿的公共布局函数继续扩散偏差。

## 常见漂移与修复

| 观察到的漂移 | 修复方向 |
| --- | --- |
| 概念关系改成三条彩色说明，页面像操作手册 | 抽出组成、分工或判断关系，改成可编辑关系图；解释进 Notes，关键条件仍在页面 |
| 多数页面都是左侧三段文字、右侧图片 | 概念用图、差异用对照、操作用局部截图、案例用输入与结果；按内容选择，避免只换左右位置 |
| 短流程变成三四个高大文本卡片 | 缩短节点、让连接成为主干，将说明置于节点下方；只展示资料支持的异常分支 |
| 每页均为蓝、绿、红三条，颜色按序号轮换 | 固定主色，颜色表达角色或状态；普通说明不用逐条换色 |
| 全屏浅色章节、长句标题替代白底章节 | 复用认可章节页的背景、数字比例、短标题和布局 |
| 插画虽为扁平风，仍显得厚重 | 对照人物取景、主体面积、背景道具和阴影；生成时提供实际参考，先验证一张入页效果 |
| 整张软件截图缩小后看不清 | 用原始截图作真实局部放大，保留定位上下文与少量标注；必要时拆页或现场演示 |
| 为了“内容完整”把练习原文变成每页大段文字 | 区分讲解正文、演示、练习题与参考附录，保留材料可获得性，不把附录密度推广到正文 |

以上是诊断信号，不是禁止列表。三项事实本来并列时可用三列；原文练习可以保留长文；真实产品操作需要截图。验收依据是用途、准确性和已确认参考。

## 验证范围

单页可编辑、无溢出和包结构完整属于技术验收。构图、叙事节奏与参考一致属于视觉验收。两者分别检查。说明实际完成的是规则检查、代表页试制还是整套重制，不能把小样通过描述为全套课件已经优化。
