# 视觉系统与信息图规范

## 优先级

用户给定品牌规范 / 风格参考 > 已有演示文稿的系统 > 这里的可选默认风格。

## 1. 默认视觉档案：Modern Friendly Tech

适合技术培训、软件产品说明、组织协作与概念演示：

- 16:9、白或淡色背景、留白充足；深色石墨正文。
- 明快但克制的强调色，可用亮蓝、青绿、珊瑚橙、黄色、紫色。
- 现代无衬线字体；中文首选可用的苹方/思源黑体，英文 Inter 或接近的替代字体。
- 形状圆润但不过分“卡片化”；信息图优先线条清晰、对齐精准。
- 人物场景使用二维扁平矢量、少阴影、无拟真质感的编辑插画。

可选配色起点（不是必须遵循的品牌色）：

| 用途 | 参考色 |
|---|---|
| 主蓝 | `#356CF5` |
| 深蓝 | `#1D438D` |
| 淡蓝 | `#E8EEFF` |
| 珊瑚橙 | `#FF7853` |
| 黄 | `#FFC619` |
| 青绿 | `#08C8B5` |
| 紫 | `#6E49E8` |
| 深文字 | `#111827` |
| 次级文字 | `#64748B` |

以上只是风格基线。用户指定严肃金融、极简黑白、品牌色、深色风格时必须适应。

## 2. 字级与布局建议

常见 16:9 幻灯片：

| 元素 | 参考字号 |
|---|---|
| 封面标题 | 38–52 pt |
| 内容标题 | 28–38 pt |
| 结论 / 金句 | 23–32 pt |
| 重要短文本 | 18–24 pt |
| 信息图标签 | 15–20 pt |
| 表格 | 14–18 pt |
| 脚注 | 11–14 pt |

应结合实际投影尺寸调节；优先删字或拆页，不要通过缩小字号解决页面超载。

区分工具单位。上表使用 PowerPoint 点数；采用像素模型的工具在 96 dpi 下约为 `1 pt = 1.333 px`，例如 24 px 约为 18 pt。已有课件先保留实际字体，确认缺失后再选择替代字体并渲染验证。

1280 × 720 画布可参考左右 64 px 的安全边距、统一标题起点与内容区域；这些是布局起点，不应限制不同品牌、屏幕比例或既有模板。

## 3. 最有效的 10 类布局

1. **封面 Hero**：一句短标题 + 独立概念插画。
2. **章节 Divider**：大编号、短标题、适度留白。
3. **观点 + 插画**：左标题右图片，或相反。
4. **抽象类比**：一个中央图形 + 2–3 个短标签。
5. **递进阶梯**：三个阶段逐步递进，避免长描述。
6. **两列对比**：前后、新旧、静态/动态等。
7. **技术架构**：按边界分层，箭头注明数据/控制流。
8. **业务流程**：主流程横向，异常分支置于下方。
9. **聚焦表格**：只展示讲解所需行列；复杂表格在附件或备注。
10. **问题 / 互动页**：大问题 + 形象场景，留给现场讨论。

间隔安排章节页、场景页、工程图和纯问题页，形成阅读节奏。避免连续大量模板化卡片。

## 4. 图表语法

- 箭头方向不能含糊；区分同步/异步/反馈时使用一致符号。
- 技术流程默认左→右、上→下；循环回路另用显著回环。
- 分层架构自上而下表达：入口/触发→编排/执行→工具/数据。
- 每个节点标签尽量简短（常见为 2–7 个汉字），精确定义进备注。
- 复杂图先画主干；次要分支拆页或用浅色弱化。
- 表格表头对比明显但克制，避免粗黑全框网格。
- 默认浅色主题可采用浅蓝表头、白色正文、细横线和深色语义强调，详见 [现代原生表格](native-tables.md)。实际检查旧表格样式是否叠加意外边框或色带。
- 图表要有真实量纲、数据范围、数值口径和来源；未经证实的数字只能清楚标注“示意”。

## 5. 关于插画和 UI

- ImageGen 负责人物、场景、氛围和概念的记忆点。
- 精确软件 UI、架构箭头、表格、数字和文字负责信息传递，不要交给生成图片去猜。
- 用户提供原始截图时优先使用；未提供的 UI 可以做示意，但必须明确是示意。
- 保持图片本身无文字，避免中文伪字、错误标签和翻译问题。

## 6. 无障碍与投影适配

- 检查色彩对比，避免浅蓝字叠加浅蓝底。
- 不单独用颜色表示成功/失败；辅以形状或文字。
- 字号适合会议室投影而非仅适合笔记本屏幕。
- 图片裁切不能剪掉关键动作、人物表情或信息对象。
