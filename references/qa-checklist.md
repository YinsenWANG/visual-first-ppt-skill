# 演示文稿交付前 QA 清单

## A. 内容与结构（阻断项）

- [ ] 完全响应用户目标和既有资料，没有丢失核心观点。
- [ ] 未编造事实、引用、评价指标、案例结果和软件截图。
- [ ] 每个独立 PPT 都有独立封面、清晰章节、总结、独立封底（如用户要求）。
- [ ] 技术图组件名称准确，连接方向正确，分支/回环条件准确。
- [ ] 若系列课件，前后概念一致，术语一致，不互相矛盾。
- [ ] 增补时读过最新 PPT、Notes 和原始资料的嵌入表格；核心知识有覆盖对照。
- [ ] 来源版本与授课时间冲突已处理并说明依据，未静默改变课程安排。

## B. 信息密度（现场讲演重点）

- [ ] 每页只有一个主要理解重点。
- [ ] 标题是观点或明确主题，而非空泛的“概述”。
- [ ] 不是从文档逐段拆页，没有六七条密集 bullet 堆叠。
- [ ] 复杂解释进入 Speaker Notes，没有丢失课程知识深度。
- [ ] 用户嫌内容太多时，减轻单页密度，而非盲目砍总页数。
- [ ] 需要精确呈现的 Node List、图表、公式未被过分简化。
- [ ] 用户要求更深入时，已补原理、判断依据、契约、案例、异常或验收；新增知识有可见锚点。
- [ ] 增补没有靠重复口号、缩小字号或单纯扩写 Notes 完成。
- [ ] 演示、讨论、练习和评审时间计入总安排，未因增加页数被挤掉。

## C. 视觉系统

- [ ] 用户提供的风格参考被正确使用，未无故替换成另一种风格。
- [ ] 色彩、字体、插画和信息图语言统一。
- [ ] ImageGen 原创插画用于需要人物、协作和概念表达的页面（若工具可用）。
- [ ] 图像没有怪异肢体、伪文字、复杂无意义 UI。
- [ ] 连续页面不会重复完全相同的“三卡片”布局。
- [ ] 封面与封底有独立的视觉主题；章节页留白充分。
- [ ] 局部修订保留认可的插画和视觉系统，未无故重新生成整套素材。

## D. 工程制作与可编辑性（阻断项）

- [ ] PPTX 实际可打开，页面尺寸正确。
- [ ] 标题、正文、技术标注、数据、表格与精确图形尽量可编辑。
- [ ] 没有将所有幻灯片做成一张大图片。
- [ ] 文字不溢出、不重叠、不乱码；字体替换后仍可阅读。
- [ ] 图片没有意外拉伸、模糊、误裁切。
- [ ] 表格投影可读、列宽适当、数字保留完整。
- [ ] Speaker Notes 存在且与对应页匹配；若不支持已另交注释文件。
- [ ] 表格仍为原生 Table；旧主题未叠加意外网格、粗线或行带，状态色有文字说明。
- [ ] 样式修改保留原有文字、数值、Notes、页序与其他对象，结构修改有明确任务依据。

## E. 真正的渲染检查（阻断项）

- [ ] 新建课件逐页实际渲染检查；编辑时重新渲染全部修改页。只有证明其他内容不变且其旧渲染已检查，才复用未变页面的预览，否则重渲染全套。
- [ ] 检查过封面、章节页、最密集的图表页和封底。
- [ ] 修改后重新渲染问题页，而非只修改源码不复核。
- [ ] 不声称工具操作或文件生成成功，除非已核实结果。
- [ ] 总览与放大检查均完成；修改后 PDF、缩略图和 ZIP 对应最终 PPTX。
- [ ] 明确实际验证方式，未将包检查或工具渲染说成 PowerPoint / Keynote 客户端检查。

## F. 加权评分参考（非硬性）

| 维度 | 权重 |
|---|---:|
| 目的适配 / 现场可讲性 | 25% |
| 内容与技术准确性 | 25% |
| 视觉创意 / 插画质量 | 20% |
| 结构化图表表现 | 15% |
| 视觉一致性 | 10% |
| 可编辑性和交付完整性 | 5% |

任何阻断项都应先修复，不以加权总分掩盖严重错误。
